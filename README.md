# 🔬 BioRetos · Biología y Geología 1º ESO

**BioRetos** es una aplicación web interactiva y gamificada diseñada específicamente para estudiantes de 1º de ESO (12-13 años) para repasar y dominar los contenidos curriculares de Biología y Geología mediante retos, pensamiento crítico y el método científico.

---

## 🌟 Características Principales

- **Estructura Modular por Temas (Acordeón):**
  - **Tema 1: La Investigación Científica** (88 preguntas en 8 apartados curriculares).
  - Bloques colapsables independientes: abre un tema y el resto se cierra automáticamente.
  - Permite marcar y combinar apartados de un tema o de varios según las necesidades de la clase.
- **Iconos Vectoriales Nativos (SVG):**
  - Cero dependencias de fuentes del sistema o emojis no soportados: visualización 100% nítida y garantizada en cualquier dispositivo (Linux, Windows, ChromeOS, tabletas, móviles).
- **Retroalimentación Pedagógica Inmediata:**
  - Si el alumno falla, se resalta la respuesta correcta con una **tarjeta explicativa de alto contraste** justificando científicamente la solución.
  - Repaso final de fallos con explicaciones detalladas.
- **Gamificación atractiva para 13 años:**
  - Puntos de Experiencia (XP), multiplicadores por racha de aciertos (`🔥`), trofeos y rangos científicos.
  - Efectos sonoros sintetizados offline mediante la **Web Audio API** (con botón de silencio `🔊`/`🔇`).
  - Animación de confeti de celebración en altas puntuaciones.
- **100% Autónomo y Offline:**
  - Todo el código (HTML, CSS, JS, banco de preguntas y sonidos) está autocontenido en un único archivo. No requiere servidor, bases de datos ni conexión a internet.

---

## 💻 Uso Local sin Internet
Simplemente haz doble clic en `index.html` o `ByG Retos.html` para abrirlo en cualquier navegador (Google Chrome, Firefox, Safari, Microsoft Edge).
